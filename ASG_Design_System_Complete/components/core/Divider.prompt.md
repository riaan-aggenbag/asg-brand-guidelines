# Divider

Hairline rule, the signature short brass rule-line, or a centred tracked-caps label.

```jsx
<Divider />
<Divider brass center />
<Divider label="Itinerary" />
<Divider orientation="vertical" />
```

Use `brass` for the editorial rule-line moment (under eyebrows/section heads). `label` flanks a tracked label with hairlines.
