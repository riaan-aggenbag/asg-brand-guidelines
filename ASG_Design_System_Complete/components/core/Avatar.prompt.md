# Avatar

Specialist or guest portrait. Falls back to initials of `name` when no `src`.

```jsx
<Avatar src="/team/riaan.jpg" name="Riaan Aggenbag" size="lg" ring />
<Avatar name="Sarah K" size="sm" />
```

sizes: `xs` · `sm` · `md` · `lg` · `xl`. `ring` adds a brass ring (use for the assigned specialist).
