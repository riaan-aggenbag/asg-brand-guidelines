# IconButton

Square, icon-only control. Always pass `label` (accessibility + tooltip).

```jsx
<IconButton icon="search" label="Search" />
<IconButton icon="sliders" label="Filters" variant="outline" />
<IconButton icon="arrow-right" label="Next" variant="solid" size="lg" />
```

variants: `ghost` (default) · `outline` · `solid` (brass). sizes: `sm` · `md` · `lg`.
