# Icon

Thin-stroke line icon (Lucide geometry) that inherits `currentColor`. The brand book defines no icon set — Lucide is the chosen substitute for its restrained line weight.

```jsx
<Icon name="arrow-right" size={20} />
<Icon name="map-pin" size={16} color="var(--accent)" />
```

Default size 20, stroke 1.75. Names include navigation (`arrow-right`, `chevron-down`, `menu`, `close`), action (`search`, `filter`, `sliders`, `plus`), travel (`map-pin`, `compass`, `binoculars`, `leaf`, `globe`), and meta (`calendar`, `clock`, `user`, `star`, `phone`, `mail`). See `ICON_NAMES`.
