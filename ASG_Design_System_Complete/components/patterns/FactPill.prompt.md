# FactPill

Frosted stat badge for hero photography — translucent white fill, hairline border, backdrop blur, brass ✦ prefix. Facts over a photo always get this surface, never bare text.

```jsx
<div style={{display:'flex',flexWrap:'wrap',gap:12}}>
  <FactPill>Big Five</FactPill>
  <FactPill>Malaria-Free</FactPill>
  <FactPill>9,000 hectares</FactPill>
</div>
```

`glyph={false}` drops the ✦. Only for use over imagery/dark grounds (white text).
