# EnquiryChecklist

Reasons-to-enquire-direct list with brass check circles (white ✓ in a 22px brass disc). Sits in the "Why enquire direct" panel.

```jsx
<EnquiryChecklist items={[
  "Lodge's contracted rate — no markup",
  "Personal advice from safari specialists",
  "A tailored itinerary for your dates",
  "No payment to enquire — reply within 24 hours",
]} />
```

`columns={1}` for narrow placements. Text colour follows the theme (`--text-body`).
