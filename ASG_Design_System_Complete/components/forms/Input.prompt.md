# Input

Single-line text field. Label, optional leading icon, hint, and error states.

```jsx
<Input label="Email" type="email" placeholder="you@example.com" required />
<Input label="Search lodges" icon="search" placeholder="Sabi Sand…" />
<Input label="Travel dates" error="Please choose your dates" />
```

`hint` shows helper text; `error` replaces it and turns the field red.
